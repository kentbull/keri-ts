# Historical plans

Files here preserve superseded scope, bootstrap proposals and past investigations.
Unchecked boxes and historical blockers are not current implementation claims or
authorization to restart work. Use [active plans](../plans/README.md) and
[current designs](../design-docs/README.md).

- `cesr/`: atomic parser architecture, initial parser plans and primitive research.
- `cli/`: initial init/incept bootstrap plans.
- `db/`: original LMDB implementation inventory and transaction research.
- `exchange/`: initial combined multisig/IPEX port plan.
- `packaging/`: delivered package ownership/dependency migrations.
- `quality/`: previous quality/test restructuring plans.

Original historical dates and proposals remain intact. Git history supplies
routine development chronology; do not append new execution logs to these files.
