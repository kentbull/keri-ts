Support group apply, offer, agree and spurn authoring with member approval/fanout, exact wrapper selection and elected external delivery. A single command host owns progress and cleanup. Persist local single-sig conversation history before delivery, validate accepted predecessors and known counterparties before signing, and collect stored peer child proofs during explicit join. These four commands accept `--approval-timeout` (default 60 seconds; zero returns pending group state) and report group status and message identities separately from transport destinations. Grant/admit settlement remains a separate release cut.
