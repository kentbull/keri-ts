A host serves the OOBI of an identifier whose accepted, uncut end-role record names one of the host's local identifiers as `eid` in the requested role, so a group's agent answers for the group even when `hostedPrefixes` is empty. Identifiers with no accepted end role at the host, other roles, and cut roles still return 404; `hostedPrefixes` remains the direct shortcut and, when non-empty, is the operator's scope: the named agent must be in it. Empty or absent, any local identifier qualifies.
